# 运动控制函数重构完整方案

## 📋 概述

本文档详细说明了运动控制函数的重构方案，包括需求分析、实施计划、代码实现和测试方法。

---

## 🎯 需求分析

### 变更需求

1. **move_distance → move_arc**
   - 新功能：圆弧移动控制
   - 适用车型：阿克曼/差速轮
   - 添加：PID闭环控制

2. **move_distance_xy → move_translate**
   - 新功能：平面直线平移
   - 适用车型：麦轮
   - 添加：PID闭环控制

3. **rotate_angle（增强）**
   - 保持原函数名和参数
   - 添加：PID闭环控制
   - 提高精度

---

## 🏗️ 实施方案对比

### 方案A：保留旧函数（推荐）✅

**描述**：添加新函数，保留旧函数

**优点**：
- ✅ 向后兼容
- ✅ 用户可以逐步迁移
- ✅ 可以对比测试新旧实现
- ✅ 风险较低

**缺点**：
- ⚠️ 代码量增加
- ⚠️ 需要维护两套功能

**实施**：
```python
# 保留
def move_distance(self, distance, speed): ...
def move_distance_xy(self, x_dist, y_dist, speed_x, speed_y): ...

# 新增
def move_arc(self, distance, speed, radius): ...
def move_translate(self, x_dist, y_dist, speed): ...
def rotate_angle(self, angle_degrees, angular_speed, use_pid=True): ...
```

### 方案B：直接替换（不推荐）❌

**描述**：删除旧函数，只保留新函数

**优点**：
- ✅ 代码更简洁
- ✅ 强制使用新功能

**缺点**：
- ❌ 破坏向后兼容
- ❌ 现有代码无法运行
- ❌ 风险高

### 方案C：分阶段实施（最优）⭐

**阶段1**：实现新函数（保留旧函数）
**阶段2**：测试和调优
**阶段3**：标记旧函数为deprecated
**阶段4**：逐步删除旧函数（用户决定）

**推荐采用方案C的阶段1**

### 1. PID控制器类

```python
class PIDController:
    """
    简单的PID控制器
    用于运动控制的闭环反馈
    """
    
    def __init__(self, kp, ki, kd, output_limit=None):
        """
        初始化PID控制器
        
        参数:
            kp (float): 比例增益
            ki (float): 积分增益  
            kd (float): 微分增益
            output_limit (tuple): 输出限制 (min, max)，None表示无限制
        """
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.output_limit = output_limit
        
        # 状态变量
        self.prev_error = 0.0
        self.integral = 0.0
        self.last_time = None
    
    def update(self, error, dt=None):
        """
        更新PID控制器并计算输出
        
        参数:
            error (float): 当前误差（目标值 - 实际值）
            dt (float): 时间间隔（秒），None则使用默认值0.1
        
        返回:
            float: PID控制输出
        """
        if dt is None:
            dt = 0.1
        
        # 比例项
        p_term = self.kp * error
        
        # 积分项（带抗饱和）
        self.integral += error * dt
        # 限制积分项防止饱和
        max_integral = 10.0
        self.integral = max(min(self.integral, max_integral), -max_integral)
        i_term = self.ki * self.integral
        
        # 微分项
        if dt > 0:
            derivative = (error - self.prev_error) / dt
            d_term = self.kd * derivative
        else:
            d_term = 0.0
        
        # 保存当前误差用于下次计算
        self.prev_error = error
        
        # 计算总输出
        output = p_term + i_term + d_term
        
        # 输出限制
        if self.output_limit:
            min_out, max_out = self.output_limit
            output = max(min(output, max_out), min_out)
        
        return output
    
    def reset(self):
        """重置PID控制器状态"""
        self.prev_error = 0.0
        self.integral = 0.0
        self.last_time = None
```

### 2. move_arc 实现

```python
def move_arc(self, distance, speed, radius):
    """
    圆弧移动（针对阿克曼/差速轮）
    使用PID控制实现精确的圆弧轨迹
    
    参数:
        distance (float): 圆弧长度/行驶里程，单位米 (m)
        speed (float): 线速度，单位 m/s
        radius (float): 转弯半径，单位米 (m)
            - radius > 0: 向左转弯
            - radius < 0: 向右转弯  
            - radius = 0 或很大: 直线行驶
    
    返回:
        bool: 成功返回True，失败返回False
    """
    import math
    import time
    
    # 检查车型
    if self.robot_type == "mec":
        print("[Error] move_arc: 麦轮车型请使用 move_translate")
        return False
    
    # 参数检查
    if distance <= 0:
        print("[Error] move_arc: distance必须为正数")
        return False
    if speed <= 0:
        print("[Error] move_arc: speed必须为正数")
        return False
    
    # 计算角速度
    # ω = v / r
    if radius == 0 or abs(radius) > 1000:
        # 直线行驶
        angular_velocity = 0.0
    else:
        angular_velocity = speed / radius
    
    # 创建PID控制器（用于速度控制）
    # 这些参数可能需要根据实际机器人调整
    speed_pid = PIDController(
        kp=1.0,  # 比例
        ki=0.1,  # 积分
        kd=0.05, # 微分
        output_limit=(-speed*1.5, speed*1.5)
    )
    
    print(f"[Info] move_arc: 开始圆弧移动")
    print(f"       距离={distance}m, 速度={speed}m/s, 半径={radius}m")
    
    # 获取起始位置
    start_pose = self._get_odom()
    if not start_pose:
        print("[Error] move_arc: 无法读取起始位置")
        return False
    
    traveled_distance = 0.0
    last_pose = start_pose
    last_time = time.time()
    
    fail_count = 0
    max_fails = 5
    
    try:
        while traveled_distance < distance:
            # 获取当前位置
            current_pose = self._get_odom()
            if not current_pose:
                fail_count += 1
                if fail_count >= max_fails:
                    print("[Error] move_arc: 多次无法读取位置，停止运动")
                    self.set_velocity(0, 0, 0)
                    return False
                time.sleep(0.1)
                continue
            
            fail_count = 0
            
            # 计算移动距离
            dx = current_pose["x"] - last_pose["x"]
            dy = current_pose["y"] - last_pose["y"]
            step_distance = math.sqrt(dx*dx + dy*dy)
            traveled_distance += step_distance
            
            # 计算剩余距离
            remaining = distance - traveled_distance
            
            # PID控制速度
            current_time = time.time()
            dt = current_time - last_time
            
            # 使用PID修正速度
            error = remaining
            if remaining < 0.1:  # 接近目标，减速
                target_speed = speed * (remaining / 0.1)
                target_speed = max(target_speed, 0.05)
            else:
                target_speed = speed
            
            # 发送速度命令
            # 对于圆弧，vx=speed, vy=0, wz=angular_velocity
            self.set_velocity(target_speed, 0.0, angular_velocity)
            
            # 更新状态
            last_pose = current_pose
            last_time = current_time
            
            time.sleep(0.1)
        
        # 停止
        self.set_velocity(0, 0, 0)
        print(f"[Info] move_arc: 完成，实际行驶 {traveled_distance:.3f}m")
        return True
    
    except KeyboardInterrupt:
        print("[Warning] move_arc: 用户中断")
        self.set_velocity(0, 0, 0)
        return False
    except Exception as e:
        print(f"[Error] move_arc: {e}")
        self.set_velocity(0, 0, 0)
        return False
```

### 3. move_translate 实现

```python
def move_translate(self, x_dist, y_dist, speed):
    """
    平面直线平移（针对麦轮）
    使用PID控制实现精确的平面移动
    
    参数:
        x_dist (float): X轴移动距离，单位米 (m)
            - 正数: 车头方向前进
            - 负数: 后退
        y_dist (float): Y轴移动距离，单位米 (m)
            - 正数: 向左平移
            - 负数: 向右平移
        speed (float): 合成线速度，单位 m/s（必须为正数）
    
    返回:
        bool: 成功返回True，失败返回False
    """
    import math
    import time
    
    # 检查车型
    if self.robot_type != "mec":
        print("[Error] move_translate: 此功能仅适用于麦轮车型")
        return False
    
    # 参数检查
    if speed <= 0:
        print("[Error] move_translate: speed必须为正数")
        return False
    
    # 计算总距离和方向
    total_distance = math.sqrt(x_dist*x_dist + y_dist*y_dist)
    if total_distance < 0.01:
        print("[Warning] move_translate: 移动距离太小，忽略")
        return True
    
    # 计算速度分量
    vx = speed * (x_dist / total_distance)
    vy = speed * (y_dist / total_distance)
    
    # 创建PID控制器
    pid_x = PIDController(
        kp=1.2,
        ki=0.15,
        kd=0.08,
        output_limit=(-speed*1.5, speed*1.5)
    )
    
    pid_y = PIDController(
        kp=1.2,
        ki=0.15,
        kd=0.08,
        output_limit=(-speed*1.5, speed*1.5)
    )
    
    print(f"[Info] move_translate: 开始平移")
    print(f"       X={x_dist}m, Y={y_dist}m, 速度={speed}m/s")
    
    # 获取起始位置
    start_pose = self._get_odom()
    if not start_pose:
        print("[Error] move_translate: 无法读取起始位置")
        return False
    
    start_x = start_pose["x"]
    start_y = start_pose["y"]
    target_x = start_x + x_dist
    target_y = start_y + y_dist
    
    fail_count = 0
    max_fails = 5
    last_time = time.time()
    
    try:
        while True:
            # 获取当前位置
            current_pose = self._get_odom()
            if not current_pose:
                fail_count += 1
                if fail_count >= max_fails:
                    print("[Error] move_translate: 多次无法读取位置，停止运动")
                    self.set_velocity(0, 0, 0)
                    return False
                time.sleep(0.1)
                continue
            
            fail_count = 0
            
            # 计算误差
            error_x = target_x - current_pose["x"]
            error_y = target_y - current_pose["y"]
            error_distance = math.sqrt(error_x*error_x + error_y*error_y)
            
            # 到达目标
            if error_distance < 0.02:  # 2cm精度
                break
            
            # PID控制
            current_time = time.time()
            dt = current_time - last_time
            
            # 计算PID输出
            control_x = pid_x.update(error_x, dt)
            control_y = pid_y.update(error_y, dt)
            
            # 速度限制
            control_speed = math.sqrt(control_x*control_x + control_y*control_y)
            if control_speed > speed:
                scale = speed / control_speed
                control_x *= scale
                control_y *= scale
            
            # 发送速度命令
            self.set_velocity(control_x, control_y, 0.0)
            
            last_time = current_time
            time.sleep(0.05)
        
        # 停止
        self.set_velocity(0, 0, 0)
        print(f"[Info] move_translate: 完成")
        return True
    
    except KeyboardInterrupt:
        print("[Warning] move_translate: 用户中断")
        self.set_velocity(0, 0, 0)
        return False
    except Exception as e:
        print(f"[Error] move_translate: {e}")
        self.set_velocity(0, 0, 0)
        return False
```

### 4. rotate_angle 增强实现

```python
def rotate_angle(self, angle_degrees, angular_speed, use_pid=True):
    """
    原地旋转（增强PID控制版本）
    
    参数:
        angle_degrees (float): 旋转角度，单位度
            - 正数: 逆时针旋转
            - 负数: 顺时针旋转
        angular_speed (float): 角速度，单位 rad/s
        use_pid (bool): 是否使用PID控制（默认True）
    
    返回:
        bool: 成功返回True，失败返回False
    """
    import math
    import time
    
    # 角度转弧度
    target_angle_rad = math.radians(angle_degrees)
    
    # 获取起始姿态
    start_pose = self._get_odom()
    if not start_pose:
        print("[Error] rotate_angle: 无法读取起始姿态")
        return False
    
    start_theta = start_pose["theta"]
    target_theta = start_theta + target_angle_rad
    
    # 创建PID控制器（如果启用）
    if use_pid:
        angle_pid = PIDController(
            kp=2.0,
            ki=0.2,
            kd=0.1,
            output_limit=(-angular_speed*1.5, angular_speed*1.5)
        )
    
    print(f"[Info] rotate_angle: 开始旋转 {angle_degrees}度")
    
    fail_count = 0
    max_fails = 5
    last_time = time.time()
    
    # 阿克曼车型的特殊处理
    if self.robot_type == "akm":
        v_x = 0.05
    else:
        v_x = 0.0
    
    try:
        while True:
            # 获取当前姿态
            current_pose = self._get_odom()
            if not current_pose:
                fail_count += 1
                if fail_count >= max_fails:
                    print("[Error] rotate_angle: 多次无法读取姿态，停止运动")
                    self.set_velocity(0, 0, 0)
                    return False
                time.sleep(0.1)
                continue
            
            fail_count = 0
            
            # 计算角度误差
            current_theta = current_pose["theta"]
            error = target_theta - current_theta
            
            # 归一化到[-π, π]
            while error > math.pi:
                error -= 2 * math.pi
            while error < -math.pi:
                error += 2 * math.pi
            
            # 检查是否到达
            if abs(error) < math.radians(1.0):  # 1度精度
                break
            
            # 计算控制输出
            if use_pid:
                current_time = time.time()
                dt = current_time - last_time
                w_z = angle_pid.update(error, dt)
                last_time = current_time
            else:
                # 简单比例控制
                if abs(error) < math.radians(10):
                    w_z = angular_speed * 0.3 * (error / math.radians(10))
                else:
                    w_z = angular_speed if error > 0 else -angular_speed
            
            # 发送速度命令
            self.set_velocity(v_x, 0.0, w_z)
            time.sleep(0.05)
        
        # 停止
        self.set_velocity(0, 0, 0)
        print(f"[Info] rotate_angle: 完成")
        return True
    
    except KeyboardInterrupt:
        print("[Warning] rotate_angle: 用户中断")
        self.set_velocity(0, 0, 0)
        return False
    except Exception as e:
        print(f"[Error] rotate_angle: {e}")
        self.set_velocity(0, 0, 0)
        return False
```

## 📊 PID参数建议

### 默认参数

| 函数 | Kp | Ki | Kd | 说明 |
|------|----|----|----|----|
| move_arc | 1.0 | 0.1 | 0.05 | 速度控制 |
| move_translate | 1.2 | 0.15 | 0.08 | X/Y方向控制 |
| rotate_angle | 2.0 | 0.2 | 0.1 | 角度控制 |

### 调优指南

1. **Kp（比例）**：
   - 增加Kp：响应更快，但可能振荡
   - 减小Kp：响应更慢，但更稳定

2. **Ki（积分）**：
   - 增加Ki：消除稳态误差
   - 过大Ki：可能导致超调

3. **Kd（微分）**：
   - 增加Kd：减少振荡，提高阻尼
   - 过大Kd：对噪声敏感

## 🚨 注意事项

### 安全性

1. **首次测试**
   - 建议在安全空间测试
   - 使用低速度（0.1-0.2 m/s）
   - 准备好急停

2. **PID调优**
   - 从保守参数开始
   - 逐步增大响应速度
   - 避免过激参数

3. **硬件限制**
   - 注意机器人的最大速度
   - 注意转弯半径的物理限制
   - 考虑地面摩擦力

### 兼容性

1. **旧代码迁移**
   - 提供迁移示例
